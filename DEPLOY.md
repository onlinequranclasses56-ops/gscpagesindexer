# Deploying GSC Indexer to the cloud

> Cloudflare's drag-and-drop (Pages) only hosts **static** websites — no
> Python, no database — so this app cannot run there. Below are the two
> simplest real options. Render is recommended.

## Option 1 — Render (recommended, ~10 minutes)

1. Put this folder on GitHub (GitHub Desktop app is easiest: add the
   folder, publish). Or upload the files via github.com "Add file".
2. Go to **render.com** → **New +** → **Blueprint** → connect the repo →
   **Apply**. Render reads `render.yaml` and sets everything up
   (including a 1 GB persistent disk so your database survives restarts).
3. Add your Google key: in the service's **Environment** tab →
   **Secret Files** → add a file, e.g. `/etc/secrets/key1.json`, and paste
   the service-account JSON contents.
4. Open your app URL → **Settings** → paste `/etc/secrets/key1.json` as a
   key path → **Save**. Then bulk-import your sites.

The daily sync runs automatically on the server. One gunicorn worker is
configured so the scheduler never double-runs.

**Protect the dashboard with a password** (recommended — it manages all your
client sites): in the service's **Environment** tab → **Environment Variables**
→ add `GSC_INDEXER_PASSWORD` with a strong password you choose → **Save**.
The app will ask for it on every visit. (Do NOT use "Generate value" — you
need to know the password yourself.)

**AI Index Analyst (optional):** each property page has an "Analyze with AI"
button that reads the property's real coverage data and suggests prioritized
actions. To enable it, add an Environment Variable `AI_API_KEY` with your
provider key (works with any OpenAI-compatible API; optional `AI_BASE_URL`
and `AI_MODEL`). The AI never sees your Google keys.
Tip for Groq (free): set `AI_BASE_URL=https://api.groq.com/openai/v1` and
`AI_MODEL=openai/gpt-oss-20b` — the `llama-3.3-70b-versatile` ID is
Enterprise-only and returns `model_not_found` on free keys.

**Bing + IndexNow (optional):** alongside Google pushes, the tool can submit
URLs to Bing Webmaster Tools (`SubmitUrlBatch`, up to ~10,000/day/site) and
ping IndexNow (Bing, Yandex, …). Honest limit: Bing has no per-URL
"indexed / not indexed" API — the tool tracks *submissions*, not Bing index
status. To enable:
1. Add each site in [Bing Webmaster Tools](https://www.bing.com/webmasters)
   (it can import your verified GSC properties) and verify ownership.
2. Bing Webmaster Tools → Settings → API → copy the API key → Render →
   Environment → add `BING_API_KEY`.
3. For IndexNow: open the tool → Settings → **🔑 IndexNow key** card →
   **Save / Generate** (leave empty to generate). The key is public by design
   (it lives in a `.txt` file), so the tool stores it safely — no env var
   needed (`INDEXNOW_KEY` env var overrides it if ever set). Then host a file
   at `https://<each-domain>/<KEY>.txt` whose content is the key.
4. In the tool: Settings → enable "Bing URL submission" and/or "IndexNow".
Submissions run automatically in the pipeline and are also available as
property-page bulk actions ("Push to Bing", "Submit via IndexNow").

## Option 2 — PythonAnywhere

1. Upload `gsc-indexer.zip` via the **Files** tab and unzip it.
2. **Web** tab → Add a new web app → Flask → Python 3.x.
3. Edit the WSGI file to:

```python
import sys
sys.path.insert(0, '/home/YOURUSERNAME/gsc-indexer')
from app import app as application
import app as appmod
appmod.seed_from_config()
appmod.schedule_daily()
appmod.scheduler.start()
```

4. In the **Files** tab, upload your service-account JSON next to the app
   and paste its path in Settings.
5. Reload the web app. (Note: the daily scheduler needs an "always-on"
   task, which requires a paid plan; otherwise use the dashboard's
   "Run all" button when you're online.)

## Notes

- Never commit `config.yaml` or `*.db` files to git (see `.gitignore`).
- `GSC_INDEXER_SECRET` is auto-generated by Render; set it manually
  anywhere else.
- Local run is still free forever: `python app.py`.
